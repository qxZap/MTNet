    When changes apply

    The console variables are written into the configs object of the /config response the game reads. Changes apply on the next game start, not in the session that is already running.

    The server panel is plain HTTP

    The dedicated-server panel on port 8091 speaks plain HTTP and is protected by a password only. Do not publish that port without TLS in front of it.

    Origin

    This file is served by the MTNet plugin from the host it was opened on. Every request goes back to that same origin — same origin — so nothing is sent anywhere else.

    Cannot reach the MTNet plugin

    The plugin did not answer on this host. It has to be running — it ships with the game — and this panel has to be opened from the port it serves.
